LinkSprig support

LinkSprig previews which local Markdown links would be affected by a proposed move inside a selected documentation folder.

Get started

Open Sample mode to try the workflow with synthetic local data. Sample results are labeled and remain separate from your live work.

Choose a documentation root, enter the existing path and proposed destination, and review affected links. Copy the change plan when you are ready to apply changes yourself.

Understand the result

The app simulates moves without moving files or rewriting links. Symlinks and inaccessible paths reduce coverage. Unsupported link forms and URL fragments remain unchecked. External links are not tested.

If access to a selected file or folder expires, choose it again and rescan. Review the latest check time and coverage before relying on a result. Clear local data removes app state and saved access without deleting your source files.
