RouteLoom Privacy Policy

Michael Lip provides RouteLoom. Endpoint settings, diagnostic observations, incident records, and session history stay on your Mac. The app has no analytics, telemetry, or developer operated backend.

During an active diagnostic session, RouteLoom sends HTTPS requests only to the endpoints you configure. Requests involve normal DNS resolution and TLS connections. The endpoint servers receive the requests and can see your source IP address. No checks run before you configure endpoints and start a session.

The app uses an ephemeral network session and does not store cookies or response bodies. It records request timing, response status, and transport errors locally. URLs with embedded credentials are rejected.

Reports are copied only when you choose to copy. Reports omit URL paths and query strings by default and can be previewed before copying. Sample mode uses bundled fictional responses and makes no requests.

Opening a support or privacy link launches your default browser. The destination website receives the normal browser request and uses its own website privacy policy.

For help, bug reports, or feedback, email lipmichal@gmail.com or open a GitHub issue.
