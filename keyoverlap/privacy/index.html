KeyOverlap Privacy Policy

Michael Lip provides KeyOverlap. Shortcut plans, proposed replacements, imported records, and settings stay in the app sandbox container on your Mac. The app does not make network requests, require an account, run analytics, or sync to a cloud service.

KeyOverlap does not listen to typing or inspect shortcuts in other apps. It does not use Input Monitoring, Accessibility controls, event taps, or application scripting. Its global shortcut opens only its own planner.

Import reads only a JSON file you explicitly select and copies its records into the app container. The app does not keep a bookmark to that file. Clipboard copies happen only when you choose to copy. You can clear local plans in Settings. Sample mode uses fictional shortcut records.

Opening a support or privacy link launches your default browser. The destination website receives the normal browser request and uses its own website privacy policy.

For help, bug reports, or feedback, email lipmichal@gmail.com or open a GitHub issue.
