NativeLedger Privacy Policy

Michael Lip provides NativeLedger. The app reads application bundle metadata and bounded main-executable headers locally. It does not inspect documents, upload inventory, run analytics, or require an account. The current inventory cache is stored inside the sandbox container. User-selected folders are saved as read-only security-scoped bookmarks in local preferences. Remove a folder in Settings to remove its saved grant. Cache data is refreshed when you rescan and is removed when the app container is deleted.

The app can read public running-application architecture information and watch authorized scan folders for changes. Sample uses synthetic app names and does not replace the saved live inventory. Background scans continue while Sample is visible. Clipboard export occurs only when you choose Copy list. Browser actions open an app-supplied website or a search in the default browser; the destination receives the normal browser request. No updates are downloaded or installed by NativeLedger.

For help, use the support link on the App Store product page. This bundled guide is available offline.
