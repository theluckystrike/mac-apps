HashDock support

HashDock compares selected destination folders with a frozen source manifest.

Get started

Open Sample mode to try the workflow with synthetic local data. Sample results are labeled and remain separate from your live work.

Choose a source folder and each destination folder. Build the source manifest, then verify every destination against that same revision. Refreshing the source requires destination checks again.

Understand the result

The app does not copy or change files. Offline folders cannot be marked verified. Symlinks, unreadable files, changing files, and cancelled checks reduce coverage. Observed change detection is not an atomic filesystem snapshot.

If access to a selected file or folder expires, choose it again and rescan. Review the latest check time and coverage before relying on a result. Clear local data removes app state and saved access without deleting your source files.
