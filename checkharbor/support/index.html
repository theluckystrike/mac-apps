Use Try Sample to explore fictional data without configuring live inputs.

Add an explicit GitHub.com owner and repository. Public repositories work without a token where API limits permit. For a private repository, use a fine grained token with Actions read access and enter it in the app.

A failure stays unresolved until a newer successful run for the same repository, workflow, and branch is observed. Acknowledge and Snooze preserve the unresolved episode. If refresh fails, check the authentication, rate limit, or stale state before retrying.

Limited API history and polling gaps can miss runs. CheckHarbor does not fetch logs or source code and cannot rerun workflows. Remove credentials in the app when a token is no longer needed.

If the global shortcut cannot be registered, choose another shortcut in Settings or open the panel from the menu bar.
