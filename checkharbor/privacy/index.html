CheckHarbor Privacy Policy

Michael Lip provides CheckHarbor. Repository settings, workflow metadata, and recovery episodes stay on your Mac. Optional personal access tokens stay in Keychain. The app has no analytics or developer operated backend.

Live refreshes send HTTPS requests to api.github.com for the repositories you configure. If you supply a token, it is sent only to api.github.com. Redirects to other hosts do not receive the Authorization header. GitHub receives the API requests and handles them under its own privacy practices.

CheckHarbor reads workflow run metadata and does not fetch repository source code or build logs. It does not request write API permissions. Public repositories can be checked without a token where GitHub API limits permit.

You can remove credentials in the app. Opening a workflow run launches github.com in your default browser, where GitHub receives the browser request. Sample mode uses bundled fictional responses and makes no network requests.

Opening a support or privacy link launches your default browser. The destination website receives the normal browser request and uses its own website privacy policy.

For help, bug reports, or feedback, email lipmichal@gmail.com or open a GitHub issue.
