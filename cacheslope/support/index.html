CacheSlope support

Use Try Sample to explore fictional data without configuring live inputs.

Choose a folder before scanning. The first complete scan records a baseline. Later complete scans show changes in logical file sizes. Those sizes are not a measurement of disk space you could reclaim.

If access is denied or a saved permission is stale, choose the folder again. Partial scans show skipped entries and are not compared as complete results. CacheSlope does not delete files or manage Docker.

If the global shortcut cannot be registered, choose another shortcut in Settings or open the panel from the menu bar.

For help, bug reports, or feedback, email lipmichal@gmail.com or open a GitHub issue.

Include the app version, macOS version, and steps to reproduce the problem. Do not include tokens, credentials, private repository names, endpoint details, file paths, or other sensitive information in public issues.
