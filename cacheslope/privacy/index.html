CacheSlope Privacy Policy

Michael Lip provides CacheSlope. Folder names, logical file sizes, saved folder permissions, snapshots, and settings stay on your Mac. The app does not read file contents, make network requests, or run analytics.

Folder access begins when you choose a folder. Saved bookmarks let the app restore that permission for later scans. Scans read file metadata within selected folders, do not follow symbolic links, and do not download cloud placeholders. Skipped entries and partial totals are shown in the app.

Copied reports may include folder names and are placed on the clipboard only when you choose to copy. Revealing a folder opens Finder. You can remove a selected root and its local snapshot history in the app. CacheSlope does not delete files or control Docker. Sample mode uses fictional snapshots.

Opening a support or privacy link launches your default browser. The destination website receives the normal browser request and uses its own website privacy policy.

For help, bug reports, or feedback, email lipmichal@gmail.com or open a GitHub issue.
