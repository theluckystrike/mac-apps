ColumnLatch support

ColumnLatch checks recurring CSV deliveries against your saved column and value rules.

Get started

Open Sample mode to try the workflow with synthetic local data. Sample results are labeled and remain separate from your live work.

Choose a CSV file and delimiter, create a column contract, and set required columns, value types, empty value policies, and a unique key. Check each new delivery against that contract.

Understand the result

The app checks CSV files rather than spreadsheets or database connections. Malformed records, duplicate headers, and unsupported input prevent a complete result. A cancelled or truncated run does not replace the last completed baseline.

If access to a selected file or folder expires, choose it again and rescan. Review the latest check time and coverage before relying on a result. Clear local data removes app state and saved access without deleting your source files.
